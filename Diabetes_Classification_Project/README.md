# Diabetes Classification and Data Management

This project explores a diabetes screening dataset, performs data cleaning and feature analysis, and compares classification models. The notebook derives a binary diabetes target from the glyhb measure and includes a PCA + SMOTE + XGBoost workflow.

## Files

- [Data_Management_Project_Final.ipynb](Data_Management_Project_Final.ipynb) — analysis and modeling notebook
- [diabetes (1).csv](diabetes%20(1).csv) — source dataset
