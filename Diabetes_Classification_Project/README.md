# Diabetes Classification and Data Management

This project explores a diabetes screening dataset, performs data cleaning and feature analysis, and applies a PCA + XGBoost classification pipeline.

## Files

- [Data_Management_Project_Final.ipynb](Data_Management_Project_Final.ipynb) — analysis and modeling notebook
- [diabetes (1).csv](diabetes%20(1).csv) — source dataset
- [df_final_processed.csv](df_final_processed.csv) — processed project data
- [pca_model.pkl](pca_model.pkl), [scaler.pkl](scaler.pkl), [xgboost_model.pkl](xgboost_model.pkl) — fitted prediction artifacts
- [app.py](app.py) and [requirements.txt](requirements.txt) — Streamlit application and dependencies

## Live Streamlit app

[Open the Diabetes Classification app](https://paunesh-diabetes-classifier.streamlit.app/)

The app is an educational demonstration only. It is not a medical device and cannot diagnose diabetes. Predictions should not be used for medical decisions.
