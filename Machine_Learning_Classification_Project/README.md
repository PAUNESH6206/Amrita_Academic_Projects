# Machine Learning Project

🚀 **Live app:** [Open the Power Fault Classifier](https://powerfaultclassifier.streamlit.app/)

This project builds and evaluates machine learning models using:
- Data preprocessing
- Feature engineering
- Model training
- Hyperparameter tuning
- Explainable AI (SHAP, LIME)

## Files
- Notebook (.ipynb)
- Dataset
- Model file (.pkl)
- requirements.txt

## How to Run
1. Install packages: `pip install -r requirements.txt`
2. Run the Streamlit app: `streamlit run app.py`
3. To explore the notebook, open it and run all cells.
